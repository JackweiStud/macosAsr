# macosAsr v0.1.0

First public open-source release for **local, on-device dictation on macOS** (developer self-build).

## Highlights

- Menu bar app with live partial + final text injection at the cursor
- **Global ⌥Z toggle** to start/stop dictation from any app (`CGEventTap`)
- Swift UI + Python ASR daemon (Qwen3-ASR via MLX)
- Settings: recognition language (Chinese / English), persisted in Application Support
- Default partial refresh interval: **0.5s**
- English menu bar UI

## Requirements

- macOS 15.0+ on **Apple Silicon**
- Xcode Command Line Tools
- Python 3.11+ (3.12 recommended; 3.14 tested locally)
- ~16 GB RAM recommended for the 0.6B model
- First run downloads the MLX model from Hugging Face (~3 GB)

## Quick start

```bash
git clone <your-repo-url> macosAsr
cd macosAsr
./scripts/setup_env.sh
./scripts/create_codesign_cert.sh   # recommended once
./scripts/build_macapp.sh
./scripts/launch_macapp.sh
```

Grant **Accessibility** and **Input Monitoring** for `macosAsrApp`, then press **⌥Z** (or use **Start Live Dictation** from the menu bar).

## Not included in this release

- Mac App Store distribution
- Pre-built `.app` binary in Releases (build from source)
- Fn+V **PTT** hotkey (current: **⌥Z Toggle** + menu)
- Settings UI for custom hotkey
- Full permission onboarding wizard

## Known limits

- Verified primarily in Notes and similar native text fields
- Requires clone + build; not a double-click installer for non-developers
- Audio and transcripts stay on device; see README third-party license section for model terms
